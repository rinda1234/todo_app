# Mobile 캘린더 일정 관리 앱

## 프로젝트 소개
본 프로젝트는 React Native(Expo)를 기반으로 한 모바일 캘린더 일정 관리 애플리케이션입니다.  
Firebase를 사용하여 사용자 로그인 및 일정 데이터를 관리하며,  
웹 애플리케이션과 동일한 Firebase 데이터베이스를 사용하여 연동됩니다.

---

## 주요 기능
- Firebase Authentication 기반 사용자 로그인
- 날짜별 일정 관리
- 월간 캘린더 화면
- 일정 추가 / 삭제 (CRUD)
- Firebase Firestore 실시간 연동
- 웹 애플리케이션과 데이터 공유

---

## 기술 스택
- Mobile Framework: React Native (Expo)
- Navigation: Expo Router
- Backend: Firebase
    - Authentication
    - Firestore Database

---

## 실행 방법

### 1. 프로젝트 설치
```bash
npm install
```
### 2. 프로젝트 실행
```bash
npx expo start
```
